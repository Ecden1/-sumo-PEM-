# -sumo-PEM-
大学创新项目时在学长的代码基础上编写的一些东西，本项目由两个文件夹组成，可以识别视频中的车流或导入PEM数据集进行SUMO仿真。
实际上做的并不理想，只是一群草台班子在努力做出一点能糊弄答辩的东西，代码也是东拼西凑但好在是做出来了些成果而且成功结项了，发到Github上纪念一下，也希望能给需要的人提供帮助，虽然确实做的很烂代码也有冗余就是了

一个是视频识别，通过给出的直道车流视频识别视频时长，以及Yolov8根据视频生成的车辆csv文件计算车流量，并据此生成路网文件进行单十字路口的sumo车辆仿真。由于Yolo视频只能生成直道，因此，这里算是只针对单个道进行车流生成，对其他道路采用相同的车流，同样的转向比例也要自己设置，所以说做的很半吊子。
一个是PEM识别，这是导师在中期答辩后指出的新方向，但是最后的结项答辩似乎没怎么用到。在真实的十字路口PEMS数据集中识别出一个十字路口构成的四个传感器，将他们的数据导入并生成对应的路网文件。
